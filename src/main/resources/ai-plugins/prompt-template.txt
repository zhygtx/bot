## 插件 SDK 规范
- 实体类放在 {{entityPackage}} 包下，标注 @Entity(description="...")
- 实体类字段标注 @Attribute(description="...")
- 方法类放在 {{methodPackage}} 包下，标注 @MethodClass(description="...")
- 方法类继承 PluginServiceBase，通过 sqlService 操作数据
- 方法标注 @Method(description="...", returnDescription="...")
- 参数标注 @Param(description="...", nullable=true/false)
- 参数类型限制：只允许 int, long, double, boolean, String, Integer, Long, Double, Boolean, List, Map, Object
- 每个方法必须有 @Method 注解和完整的 @Param 注解
- 基本类型（int, long 等）禁止标记 nullable=true

## 依赖声明
如果你的代码需要引入第三方库（如 Gson、Apache Commons 等），请在文件列表之前声明依赖：

<dependencies>
<dependency>
    <groupId>com.google.code.gson</groupId>
    <artifactId>gson</artifactId>
    <version>2.11.0</version>
    <scope>compile</scope>
</dependency>
</dependencies>

- scope 可选值：compile（默认编译和运行）、provided（由容器提供，如 generalbot-api）、runtime（仅运行时）
- 不需要依赖时不要输出 <dependencies> 块
- generalbot-api 已作为 provided 依赖引入，不要重复声明
